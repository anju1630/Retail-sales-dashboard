# Retail-sales-dashboard
power bi dashboard
📊 Retail Sales Dashboard --- Power BI

An interactive Retail Sales Dashboard built using Microsoft Power
BI to analyze sales performance, profitability, customers, products,
stores, regions, and monthly trends.

📌 Project Overview

This project transforms raw retail sales data into an interactive
business intelligence dashboard.

The dashboard helps answer questions such as:

How much total sales and profit were generated?

What is the overall profit margin?

Which product categories generate the most sales and profit?

Which stores and regions perform best in terms of sales?

How do sales change month by month?

How are sales distributed between male and female customers?

How many transactions and customers are involved?

🛠️ Tools & Technologies

Microsoft Power BI

Power Query --- data cleaning and transformation

DAX --- calculated measures and business metrics

CSV --- source datasets

📂 Dataset

The project uses four CSV datasets:

customers.csv

products.csv

sales.csv

stores.csv

Main tables

Customers - customer_id - customer_name - gender - age -
city - signup_date

Products - product_id - product_name - category -
unit_price - cost_price

Sales - sale_id - sale_date - customer_id - store_id -
product_id - quantity - total_amount

Stores - store_id - store_name - city - region

A separate DateTable was created in Power BI for time-based
analysis.

🧩 Data Model

The dashboard follows a simple star-schema style model, with Sales
acting as the central fact table.

Relationships:

customers[customer_id] → sales[customer_id]

products[product_id] → sales[product_id]

stores[store_id] → sales[store_id]

DateTable[Date] → sales[sale_date]

📈 Dashboard KPIs

The dashboard includes:

Total Sales

Total Quantity

Total Transactions

Total Customers

Total Profit

Profit Margin %

Example DAX measures:

Total Sales = SUM(sales[total_amount])

Total Quantity = SUM(sales[quantity])

Total Transactions = DISTINCTCOUNT(sales[sale_id])

Total Customers = DISTINCTCOUNT(sales[customer_id])

Total Profit =
SUMX(
    sales,
    sales[total_amount] -
    (sales[quantity] * RELATED(products[cost_price]))
)

Profit Margin % =
DIVIDE([Total Profit], [total_sales])
